# Exercise 0.5: Single Page Application diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    browser->>server: GET /exampleapp/spa.js
    server-->>browser: JavaScript file

    Note over browser: Browser executes JavaScript

    browser->>server: GET /exampleapp/data.json
